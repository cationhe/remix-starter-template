# Admin 用户手册

## 1. 权限说明
Admin 是系统的基础管理角色，负责论坛的日常运营和秩序维护。
- **基础管理权限**：拥有用户列表查看、封禁/解封、以及常规内容操作权限。
- **秩序维护者**：主要负责响应违规内容处理，维护健康的讨论环境。

## 2. 论坛管理
- **内容巡查**：在有权限的讨论区内对违规帖子或评论进行删除操作。
- **用户管理**：可进入“用户管理”页面查看用户注册信息，并对违规用户执行封禁或解封。
- **日常引导**：维护讨论区的讨论氛围，引导正确讨论方向，纠正格式错误。

## 3. 操作指南
### 3.1 用户违规处理
1. 进入“管理后台” -> “用户管理”。
2. 可通过邮箱或昵称搜索用户。
3. 点击“封禁”按钮并确认，被封禁用户将无法发帖、点赞或发表评论。

### 3.2 内容清理规范
- **删帖操作**：在帖子详情页，点击“删帖”按钮执行操作。
- **评论清理**：对违规评论点击“删除”并确认。
- **注意**：所有管理操作均会被系统自动记录到审计日志中。

### 3.3 基础数据查看
- 实时关注所负责讨论区的帖子热度与评论情况，发现异常大量发帖应及时上报。

## 4. 工作规范
- **操作记录要求**：管理行为应遵循公正客观原则，避免个人情绪干扰管理。
- **问题上报流程**：遇到技术故障（如数据库报错）、大规模恶意攻击或涉及权限越权的问题，应立即记录现象并上报给 SuperAdmin 或 TopAdmin。
- **沟通礼仪**：在处理冲突或引导讨论时，应保持专业、礼貌的态度。
