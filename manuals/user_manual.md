# User 用户手册

## 1. 权限说明
User 是论坛的基础成员，拥有参与社区互动的所有基本功能。
- **基础功能使用权**：注册后即可进行浏览、发帖、回帖、点赞等操作。
- **个人空间管理**：管理自己的个人资料、消息中心和发布的内容。

## 2. 论坛功能
- **发布内容**：在指定的讨论区发布帖子，或在已有帖子下发表评论。
- **互动交流**：
  - **楼层号**：帖子详情页的评论会显示连续的楼层号，方便定位和引用。
  - **点赞**：对优质帖子进行点赞支持（不可对自己发布的帖子点赞）。
  - **分页浏览**：帖子列表和长篇评论均支持分页，提升加载体验。
- **消息中心**：
  - **批量操作**：支持勾选多条或全选消息进行批量删除。
  - **管理员消息**：来自管理员的消息会带有特殊标记，且内容中的链接可直接点击跳转。

## 3. 操作指南
### 3.1 账号注册/登录
1. 点击首页“注册”，填写邮箱、密码及昵称。
2. 登录后可访问更多个性化功能，如个人中心和消息中心。

### 3.2 个人资料与昵称修改
1. 进入“个人中心” ( `/me` )。
2. **首次修改**：可直接修改昵称并保存。
3. **二次修改**：若已修改过一次昵称，再次修改需提交“改名申请”，等待管理员审批。审批通过后系统会发送站内信通知。

### 3.3 发布与编辑内容
1. 在讨论区点击“发帖”，填写标题与内容。
2. **编辑帖子**：发布后可重新编辑标题或正文，编辑时需勾选“我确认要保存这些修改”复选框。
3. **删帖**：作者可删除自己发布的帖子，删除前系统会要求二次确认。

### 3.4 消息管理
1. 点击导航栏“消息中心”。
2. **未读提醒**：顶部导航会实时显示未读消息数量。
3. **批量删除**：点击“全选”或勾选特定消息后，点击“删除”按钮清理收件箱。

## 4. 社区规范
- **禁止行为**：
  - 禁止发布违法违规、暴力色情内容。
  - 禁止人身攻击、恶意刷屏。
  - 禁止发布未经授权的商业广告。
- **违规后果**：严重违反规范的账号将被“封禁”，封禁期间无法发帖、点赞或参与任何互动。
