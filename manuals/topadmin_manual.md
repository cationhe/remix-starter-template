# TopAdmin 用户手册

## 1. 权限说明
TopAdmin 是系统的最高权限角色，拥有对整个系统的完全控制权。
- **系统最高权限**：可管理所有后台功能，包括用户、讨论区、存储、日志等所有模块。
- **用户权限分配**：唯一有权将用户提升或降级为 `admin`、`superadmin` 或 `topadmin` 的角色。
- **系统配置**：负责系统全局参数（如附件存储上限）的配置与维护。
- **审计与监控**：拥有查看系统完整审计日志的特权。

## 2. 论坛管理
- **全站内容管理**：可查看、编辑、删除全站所有帖子和评论；支持将帖子移动到不同讨论区。
- **全局规则设置**：定义全站发帖规范、讨论区可见性及详细的用户组权限（看/发/评/下）。
- **存储管理**：监控全站附件用量，动态调整附件总容量上限。
- **审计功能**：通过“系统日志查询”监控所有管理员和用户的敏感操作记录。

## 3. 操作指南
### 3.1 角色等级管理
1. 进入“管理后台” -> “用户管理”。
2. 搜索指定用户，点击“角色修改”。
3. **二次验证**：修改角色时必须输入当前 TopAdmin 的登录密码进行二次确认。
4. **高危操作**：涉及 `superadmin` 或 `topadmin` 等级的变动会触发系统警告，并记录详细审计日志。

### 3.2 讨论区权限配置
1. 进入“管理后台” -> “讨论区管理”。
2. **用户组权限**：可针对每个讨论区分别设置不同角色（User/Admin/SuperAdmin/TopAdmin）的访问、发帖、评论和下载权限。
3. **批量设置**：支持勾选多个讨论区进行权限的批量更新。

### 3.3 存储容量管理
1. 进入“管理后台” -> “存储容量”。
2. **用量监控**：查看当前已用容量、预留容量及剩余可用空间。
3. **上限调整**：通过滑动条或输入框调整全站总容量（范围 1GB-100GB），修改后需密码验证。
4. **状态预警**：当用量超过 90% 时系统会发出警告，超过上限将暂停全站上传。

### 3.4 系统日志查询
1. 进入“管理后台” -> “系统日志”。
2. **组合筛选**：支持按时间范围、日志等级、事件类型、操作人（昵称/ID）和操作描述关键字进行搜索。
3. **操作人联想**：输入操作人部分信息可实时下拉联想。
4. **分页浏览**：支持多页跳转，所有筛选条件均通过 URL 持久化，方便分享与追溯。

## 4. 安全规范
- **二次密码验证**：角色变更、存储调整等高敏操作必须进行二次密码验证。
- **操作日志审查**：应定期（建议每周）审查“系统日志”，重点关注角色变更和批量删除操作。
- **最小权限原则**：仅在必要时授予其他用户 SuperAdmin 权限，严控 TopAdmin 席位。
