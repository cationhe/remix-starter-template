# SuperAdmin 用户手册

## 1. 权限说明
SuperAdmin 是系统的次级管理角色，负责核心业务逻辑与内容的管理。
- **次级管理权限**：可管理大部分后台功能，如用户状态、讨论区属性、昵称审批等。
- **内容控制权**：拥有全站内容的高级管理权，包括跨分区移动帖子。
- **沟通特权**：可向全站用户发送带有特定内容链接的管理消息。

## 2. 论坛管理
- **版块管理**：可管理讨论区的描述、排序及可见性；支持对帖子进行置顶、加精、隐藏和删除。
- **帖子移区**：支持在帖子详情页直接将帖子移动到其他讨论区。
- **用户管理**：可对用户执行封禁（Banned）操作，处理违规用户。
- **审批功能**：负责审核用户的二次昵称修改申请。

## 3. 操作指南
### 3.1 昵称审批流程
1. 进入“管理后台” -> “昵称审批”。
2. 查看待处理的申请列表（包含申请人、旧昵称、新昵称及申请时间）。
3. 点击“通过”或“驳回”：
    - **通过**：用户昵称立即更新，系统自动发送站内消息通知用户。
    - **驳回**：需记录驳回原因，系统通知用户。

### 3.2 批量删除封禁帖
1. 进入“管理后台” -> “批量删除封禁”。
2. 系统会自动列出所有已被封禁用户发布的帖子。
3. 勾选需要清理的帖子，点击“批量删除”，系统将彻底清理相关数据。

### 3.3 帖子移区
1. 在帖子详情页的“管理操作”区点击“移区”按钮。
2. 在弹出的对话框中选择目标讨论区（支持搜索筛选）。
3. 确认后帖子将无刷新移动到新分区，并记录审计日志。

### 3.4 向作者发送管理消息
1. 在帖子详情页或评论列表中，点击作者昵称旁的“✉️发送消息”按钮。
2. 填写主题与正文，系统会自动附带当前内容的跳转链接（评论会自动定位到锚点）。
3. 成功发送后，消息在对方列表中会标记为“管理员”消息。

## 4. 限制说明
- **不可修改系统核心配置**：无法调整全站存储上限或修改 `wrangler.json` 环境变量。
- **不可修改高阶角色**：无权修改用户的角色等级（如提升为 Admin/SuperAdmin），该功能仅限 TopAdmin。
